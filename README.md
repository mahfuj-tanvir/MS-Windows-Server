# Enterprise Windows Server 2022 Infrastructure Deployment
Designed and implemented a multi-department enterprise infrastructure using Windows Server 2022, Hyper-V, and pfSense Firewall, providing centralized identity management, network services, and security controls.

Key Implementation:

Deployed Active Directory Domain Services (AD DS), DNS, and DHCP
Configured Hyper-V virtualization and pfSense-based network segmentation
Implemented DHCP Relay for multi-subnet IP address management
Installed and configured AD CS as an Enterprise Root CA
Created OUs, users, and Group Policies for centralized administration
Enforced security policies including USB restrictions, password policies, and account lockout settings
Deployed IPAM for centralized IP address monitoring and management

Technologies & Tools: Windows Server 2022, AD DS, DNS, DHCP, Hyper-V, pfSense, AD CS, IPAM, Group Policy (GPO), PowerShell, IPv4 Networking
